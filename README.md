# SoryOS boutique en ligne

Plateforme e-commerce moderne et native, conçue avec React 19, TypeScript, Tailwind CSS v4 et propulsée par l'API Gemini pour le support client 24/7.

## 🚀 Fonctionnalités principales

- **Catalogue Multi-Catégories Organisé** :
  - Maison & Textile (Serviettes égyptiennes, rideaux occultants, parures de lit, couettes)
  - Quincaillerie (Barres de rideau industrielles)
  - Mode & Artisanat (Caftans en soie brodés)
  - Audio, Montres & Wearables, PC & Claviers, Drones, Lifestyle & Beauté
- **Cartes Produits Interactives** :
  - Effets visuels fluides (zoom doux, élévation et ombre portée au survol)
  - Badges Choice et SuperDeals Vente Flash
  - Modale d'aperçu rapide et page produit détaillée (PDP)
- **Skeleton Loader & Transition UX** :
  - Composant de chargement squelette pour les filtres et sélections de catégories
- **Système de Fidélité & Réductions** :
  - Cagnotte de pièces (Coins) avec bonus de connexion quotidienne
  - Conversion instantanée de pièces en bons d'achat
  - Codes promo (`ALY10`, `BIENVENUE5`, `CHOICEDAY`)
- **Assistance Client 24/7 (AlyBot)** :
  - Chatbot interactif connecté à l'API Gemini pour le conseil d'achat et le suivi des commandes
- **Suivi de Colis & Checkout** :
  - Simulateur d'étapes d'expédition (douanes, transport aérien, livraison finale)
  - Sélecteur multi-devises (EUR, USD, FCFA, CAD)

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **Backend / Serveur** : Node.js, Express, tsx, @google/genai SDK
- **Bundler** : Vite 8

## 📦 Installation & Lancement

```bash
# Installer les dépendances
npm install

# Lancer en développement
npm run dev

# Compiler pour la production
npm run build
```
